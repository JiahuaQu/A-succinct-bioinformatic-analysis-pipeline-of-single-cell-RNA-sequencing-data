# A succinct bioinformatic analysis pipeline of single cell RNA sequencing data

## Abstract

 

## Introduction

With the development of new technologies, we are able to change studies from human populations to small groups, to individual humans, to different organs and tissues, to sorted cell groups, and even to single cells now. Without doubt, the single-cell RNA sequencing (scRNA-seq) is one of the most important technologies. Initially, researchers isolated single cells manually, which consumed quite a lot of time. Then gradient dilution method was used to isolate single cells into each well in a plate, exemplified by the Smart-seq2 protocol. This low-throughput but high-depth showed high sensitivity and was compatible with the profiling of the entire transcript. In contrast, the popular 10X Genomics platform adopted the high-throughput but low-depth method. It supports unique molecular identifiers (UMIs), short barcodes that are attached to transcripts before amplification, enabling the accurate bioinformatic identification of PCR duplicates. 

Accompanied by the various sequencing technologies, many different analysis platforms and methods were also developed. Similar to the bulk RNA-seq data analysis, the platforms and methods can be divided into two major categories, graphic and command line interfaces. The graphic interface includes the local and online applications. For example, Partek Flow, an online application, is recommended by the 10X Genomics. The command line interface methods are mainly established in two popular programming languages, R and Python. On one hand, R packages including SingleCellExperiment, scater and Seurat packages are available to scientists. On the other hand, for scientists who are proficient in python, scanpy library is the most popular option.

Regardless of the graphic or command line interface, R or python, the typical scRNA-seq data analysis includes the following steps: (1) count matrix generation; (2) analysis object creation; (3) quality control and low quality data filtering; (4) normalization; (5) finding variable features; (6) scaling; (7) dimension reduction; (8) clustering; (9) marker genes selection; (10) cell type annotation; (10) differential expressed genes selection; (11) pathway enrichment; and (12) visualization at each step. In addition to the above-mentioned basic analyses, further customized analyses are performed in more specific cases and correspond to personalized requirements.

Because there are many available options with complicated parameters, which are not friendly to beginners who want to make use of the single cell technology, this paper aimed to summarize our experience in scRNA-seq data analysis and provide a succinct pipeline to start the adventure of single cell study. I will demonstrate the analysis with the data generated by the 10X Genomics platform, Chromium, and using Seurat in R language.

### 1. Datasets

The 10X Genomics Chromium platform produces and stores the raw sequencing data with other necessary files in the same directory named by the sample name.  In this example, I used the FASTQ files download from one of the publicly-available data sets on the 10x Genomics support site. This example uses the [1,000 PBMC data set](https://www.10xgenomics.com/datasets/1-k-pbm-cs-from-a-healthy-donor-v-3-chemistry-3-standard-3-0-0) from human peripheral blood mononuclear cells (PBMC), consisting of lymphocytes (T cells, B cell, and NK kills) and monocytes.

### 2. Reference genome

The 10X Genomics developed a convenient software called cellranger to parse the raw data into count matrix. The cellranger software uses STAR aligner to perform the splicing-aware alignment of reads to the reference genome. The 10X Genomics also prepared and provides the compatible reference genomes. In this example, we use the latest human genome, *refdata-gex-GRCh38-2024-A*. 

```bash
cd /

# Download
```

### 3. Count matrix generation

Because there can be multiple samples in the sample table, sample.txt, in the future study, to facilitate the analysis of multiple samples, we made two bash scripts to run the programs automatically.

#### 3.1. The firs bash script, 01-cellranger_count.sh

 It is to run cellranger for each sample individually.

```bash
#!/bin/bash
#BSUB -P scRNAseq
#BSUB -J count
#BSUB -q superdome
#BSUB -n 20
#BSUB -R "span[hosts=1]"
#BSUB -R "rusage[mem=10000]"
#BSUB -oo run_%J.log
#BSUB -eo run_%J.error
#BSUB -W 3:00
#BSUB -B 
#BSUB -N 

# Load the cellranger module
module load cellranger/8.0.1

# Reference genome path
ref=/research/sharedresources/immunoinformatics/common/jqu/reference_genome/cellranger/human/refdata-gex-GRCh38-2024-A

# Path to the file listing sample details
sample_text=./sample.txt

# Get the line corresponding to the current task ID
line=$(sed -n "${num}p" ${sample_text})

# Parse each field from the line
sample=$(echo $line | awk '{print $1}')   # Original sample name
id=$(echo $line | awk '{print $2}')       # Renamed sample id
data=$(echo $line | awk '{print $3}')     # Path to FASTQ directory

# Run cellranger count
cellranger count \
  --transcriptome=$ref \
  --fastqs=$data \
  --sample=$sample \
  --id=$id \
  --nosecondary \  # Do not conduct secondary analysis to save time
  --output-dir=./count/
```

#### 3.2. The firs bash script, 02-loop_submit.sh

It is to extract each sample's information from the sample.txt file and input into the first bash script to run the program in parallel.

 ```bash
 #!/bin/bash
 #BSUB -P scRNAseq
 #BSUB -J loop
 #BSUB -q superdome
 #BSUB -n 1
 #BSUB -R "span[hosts=1]"
 #BSUB -R "rusage[mem=1000]"
 #BSUB -oo run_%J.log
 #BSUB -eo run_%J.error
 #BSUB -W 0:30
 #BSUB -B 
 #BSUB -N 
 
 # Path to the file listing sample details
 sample_text=./sample.txt
 
 # Get the number of lines in sample.txt
 total_lines=$(wc -l < ${sample_text})
 
 # Loop from 2 to total_lines
 for num in $(seq 2 ${total_lines})
 do
   # Set the environment variable num and submit the job
   export num
   bsub < 01-cellranger_count.sh
 done
 
 ```

#### 3.3. Submit jobs

```
cd /
bsub < 02-loop_submit.sh
```

The cellranger produced separate output results for each sample, including individual count matrix, cell and gene information stored in each h5 file.
